# Digital Clock and Alarm

A simple JavaScript ES6 based minor project built for **TMSL ECS**.

## Features

- Live digital clock updating every second (12-hour format with AM/PM)
- Shows full date — Day, Date, Month, Year
- Set an alarm for any time
- Alarm plays a sound when the time matches
- Alarm auto-stops after 30 seconds
- Clear alarm button to cancel anytime
- Fully **responsive** — works on both mobile and desktop

## ES6 Concepts Used

- `let` and `const`
- Arrow functions
- Template literals
- Destructuring (`let [h, m] = input.split(':')`)
- `setInterval` and `setTimeout`
- DOM manipulation

## Project Structure

```
├── index.html    → Structure / Layout
├── style.css     → Styling + Responsive Design
├── index.js      → JavaScript Logic (ES6)
├── alarm.mp3     → Alarm sound file
└── README.md     → Project Info
```

## How to Run

1. Download or clone this repository
2. Make sure `alarm.mp3` is in the same folder as `index.html`
3. Open `index.html` in any browser
4. No installation needed
